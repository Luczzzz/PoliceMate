# ADR-0001：可运行产品基线的技术栈与黑盒测试缝

- 状态：已接受
- 日期：2026-09-27
- 关联：`#27 建立松警伴侣可运行产品基线`，产品规格第 5、10、15、17 节

## 背景

仓库此前只有产品规格与决策记录，没有任何实现。第一版需要一个可运行的移动端 H5
产品外壳、一个 PoliceMate 后端，以及一条能驱动两者的移动浏览器黑盒验收测试缝。
后续切片将在此之上加入受治理内容、案情分析流程、报告和隐私/安全边界。

选型需要同时满足：

- 竖屏手机优先（360–430 CSS 像素），主要点击目标约 44×44；
- H5 不直连 Dify，密钥只在后端；
- 请求与响应携带独立契约版本，版本不兼容时停止解析；
- 测试只断言外部可观察行为，且只在 Dify 与受治理内容两个外部边界使用确定性替身。

## 决策

1. **工作区结构**：npm workspaces，包含 `apps/web`、`apps/server`、`packages/contracts`，
   黑盒测试放在顶层 `e2e/`。
2. **H5**：Vite + React + TypeScript，`react-router-dom` 负责站内导航。
   不持久化案情、事实、报告、检索词或临时标记。
3. **后端**：Fastify + TypeScript，通过 `tsx` 直接运行 TypeScript。
   开发模式下 Vite 把 `/api` 代理到后端，浏览器只看到同源。
   生产式运行时后端同时提供构建后的 H5 与 API。
4. **契约**：`@policymate/contracts` 保存共享类型与 `CONTRACT_VERSION`。
   H5 每个请求携带 `x-pm-contract-version`，响应必须回带相同版本；不一致时返回
   `contract_incompatible` 并停止解析。
5. **能力可用性**：入口可用性只由后端根据功能开关与外部边界提供者计算，
   页面不得根据文案或点击结果推断。两个入口独立降级。
6. **测试缝**：唯一的产品级测试缝是“移动浏览器 → PoliceMate 后端”。
   仅在 Dify 适配层与受治理内容源使用确定性替身，替身状态由
   `/api/test/fixtures` 控制，且仅在 `PM_ENABLE_TEST_CONTROLS=1` 时挂载。
   另有一个仅在开发模式注册的页面异常探针（`/__test__/throw`），用于在端到端测试中
   验证页面级异常状态；它在生产构建中被 `import.meta.env.DEV` 排除，不提供任何数据替身。
7. **收录控制**：H5 文档设置 `noindex`，API 响应设置 `X-Robots-Tag`；
   文案明确说明不公开网址只是分发控制，不构成认证、权限控制或保密访问。

## 后果

- 后续切片在既有契约和测试缝上扩展，无需重建外壳。
- 真实 Dify 与真实内容源接入时替换提供者实现，替身控制接口在生产环境默认关闭。
- `@policymate/contracts` 直接导出 TypeScript 源码，由 Vite 与 `tsx` 转译，
  因此不需要额外的构建步骤；代价是类型检查与运行时的解析约定必须保持一致。
- 无 root 环境需要 `scripts/install-browser-deps.sh` 准备 Chromium 系统库，
  这是环境折衷，不影响产品行为。
