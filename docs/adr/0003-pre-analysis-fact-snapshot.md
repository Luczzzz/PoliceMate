# ADR-0003：从自由案情形成分析前事实快照

- 状态：已接受
- 日期：2026-09-28
- 关联：`#29 从自由案情形成分析前事实快照`，产品规格第 6 节，决策票据 #18、#24

## 背景

第 29 号切片需要打通“脱敏自由案情输入 → 候选事实确认 → 决定性追问 →
分析前确认”的完整移动端流程。Dify 位于 PoliceMate 后端之后，返回确定性
结构；其原始自然语言不得直接展示或控制页面状态。报告生成本身属于
第 30 号切片，本切片止于用户主动确认形成不可变事实快照。

## 决策

1. **会话只存在于短暂运行内存**。后端用内存 Map 保存分析会话（随机 UUID，
   30 分钟空闲后惰性清除），不写数据库、不写日志、不出现在 URL 或遥测里。
   H5 只在当前标签页内存中持有会话标识；刷新、关闭标签页或空闲超时后
   本次分析不可恢复，与规格的标签页生命周期一致。

2. **显式后端状态机**。阶段为 `confirming_facts → collecting_answers →
   ready_to_analyze → snapshot_confirmed`，H5 只依据响应中的显式阶段与
   允许动作推进，不解析任何自然语言。对已锁定快照的一切修改返回 409。

3. **Dify 边界只做提取与选题**。`CaseAnalysisProvider` 暴露两个结构化
   能力：`extractCaseFacts`（自由文本 → 候选事实 + 独立事项提示）与
   `proposeDecisiveQuestions`（完整结构化状态 → 候选问题池）。当前实现为
   确定性替身（规则匹配，仅覆盖常见表述）；真实 Dify 接入时替换实现，
   契约与后端校验不变。后端对边界返回结果做结构校验，失败即整体拒绝
   （不展示半成品）。

4. **候选事实模型完整落到响应里**。每条候选事实携带稳定 ID、类别、
   结构化值、原始表述、事件/参与者/行为关系、来源轮次与精确程度。
   人员使用中性代号（人员甲/报案人）；模糊日期、金额、年龄、次数同时
   保留原值、规范化范围与精确程度（精确/约值/范围值/不完整范围/无法
   规范化），不发明精确值。

5. **确认权完全在民警**。提取结果一律为 `candidate`，无默认确认、无批量
   确认；民警新增的事实（含追问中的文本回答）视为民警本人确认，来源
   方式分别记录为 `officer_added` 与 `officer`。删除候选事实只设置排除
   标记，不改变状态、不进入快照正文，语义为“不纳入本次分析”。

6. **追问上限由后端强制执行**。无论边界返回多少候选问题，后端按锁定
   优先级排序后截断：最多三轮、每轮五问、总计十二问。达到上限仍有缺口
   时停止追问并保留 `limits_reached` 不足状态；没有剩余缺口时以
   `no_gaps` 结束。问题模板的选择条件基于“已确认事实”，因此文本回答
   形成的确认事实会让对应缺口自然关闭。

7. **紧急提示只由已确认事实触发**。提取边界只给事实打紧急风险标记
   （人身安全/医疗救助/未成年人保护/家庭暴力/证据灭失）；后端在展示层
   只把“已确认且未排除”的风险事实合成为报告前核验提示，列出触发事实、
   人工核验事项与固定边界说明。未经确认的关键词只会让追问边界返回一个
   `neutral_safety` 中性安全问题，不产生任何紧急结论。

8. **独立事项只提示、不阻断**。检测规则是确定性的（多个事件之间没有
   共同人员、地点或时间，或出现“另外/此外”等表述）。检测到时在事实确认
   页常驻提示建议拆分分析；产品不把独立事项合并为一个连续案情，但
   最终拆分与否由民警决定。

9. **快照不可变且内容寻址**。分析前确认接口对当前事实与回答做规范
   JSON 序列化后取 SHA-256 作为快照哈希，版本从 1 开始。确认后阶段进入
   `snapshot_confirmed`，事实、回答与追问全部锁定；补充或修改事实生成
   新快照的能力由第 31 号切片在报告工作台中实现。

10. **输入约束失败关闭**。案情输入按 Unicode 码点计数（与页面字符计数
    同口径），超过 10,000 字符明确拒绝且不截断；包含控制字符等非纯文本
    内容时明确拒绝。追问答案上限 2,000 字符，同样不截断。分析能力停用
    或 Dify 边界不可用时，分析接口整体返回 503（失败关闭），与首页入口
    降级一致。

## 后果

- 第 30 号切片接入真实 Dify 与报告生成时，只需替换
  `CaseAnalysisProvider` 实现并新增报告端点；会话、快照、上限与紧急
  提示逻辑可复用。
- 提取质量受限于替身规则集，只保证测试与演示的确定性；真实提取质量
  依赖后续 Dify 工作流，验收口径（结构校验 + 黑盒断言）不变。
- 快照哈希覆盖事实与回答的完整内容；后续若增加快照字段需同步调整哈希
  输入并记录版本语义。
- 会话表是进程内存，多实例部署时需要粘性会话或外置存储；受控试行
  单实例部署下不构成问题，生产化前需重新评估（届时仍不得持久化案情
  内容）。
