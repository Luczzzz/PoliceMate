# ADR-0011：报告首屏采用研判速览，条目以白话为主句并默认折叠

- 状态：已接受
- 关联：ADR-0009、ADR-0010；产品规格 7.1、7.4；`GLOSSARY.md` 的研判速览。

新警反馈报告过长、不直观：有用信息被埋在六模块的法言法语里。决定：报告首屏固定为**研判速览**（一句白话定性 `bottomLine`、3–5 条立即动作 `nextSteps`、至多 3 张“如果…则…”走向卡片），其后才是六模块索引。六模块与 ADR-0009/0010 规定的内容保持不变，但默认只展开核心证据核查，其余模块折叠为一行摘要。

速览内的条目为 `{ plain, legal? }`：白话主句在前，法律术语或条文仅作注释，`legal` 不得单独成句。六模块内部条目的 `plain/legal` 拆分留待试用后再定。速览由生成层（Dify）直接产出并由后端校验，前端不再从证据模块里拼凑“优先核查”。

## 约束

- `bottomLine` 必填，≤60 字；`nextSteps` 3–5 条，每条 `plain` ≤30 字并带目标模块锚点；走向卡片 ≤3 张。
- 模块折叠摘要 ≤40 字；展开默认 ≤5 条，每条 `plain` ≤50 字，其余收进“更多”；证据清单高优先级全显示；询问要点按角色分组、每角色默认 ≤3 问。数字为首版取值，试用后调整。
- 条目准入：必须是一个可执行动作，或一个会改变结论的事实；重复和泛泛提醒折叠或删除。
- 校验不通过（超长、条数不符、`plain` 为空）按生成失败降级，不由前端补造。
- 旧版本报告无速览字段时回落到现有概览；条件不足/多种可能时 `bottomLine` 改写为“现在还不能下结论，因为…”；依据不可用/生成失败不显示速览；部分失败时丢弃锚点指向失败模块的动作。
- 仍不得推荐处罚档次（ADR-0009）；契约版本号保持 `1.0`，速览为可选新字段；后端按有无字段区分新旧报告，不靠版本号，因此不需要与 Dify 工作流同步发布。

## 实现取舍

- 条件不足或存在多种可能时，速览保留；一句话缺前缀则补“现在还不能下结论，因为…”并保留原白话（放不下用固定句），首屏把走向分支排在动作之前。依据不可用、生成失败不显示速览。
- 部分模块失败后剩余动作少于 3 条时，整体不显示速览。
- 速览校验失败与其他上游输出无效同路径：整份报告失败关闭，不由前端补造。
- 模块折叠摘要在显示层截断为 40 字，完整摘要展开后可见；模块内部条目的 ≤50 字上限随 `plain/legal` 拆分一并留待试用后再定，目前不在校验里强制。
- 证据清单与询问要点的默认条数上限只在未筛选时生效，一旦用户筛选则显示全部匹配项。
- 殴打伤害类的确定性规则报告自带一份与 Dify 输出同形的速览，用于 fixture 与回归；真实 Dify 路径由提示词产出。

## 为何难以回退

契约新增字段并改变首屏结构，与此前“六模块平铺”的规格不同；Dify 提示词、校验和前端需同步迁移。
