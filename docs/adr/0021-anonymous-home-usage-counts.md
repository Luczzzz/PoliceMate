# ADR-0021：首页匿名使用次数计数

- 状态：已接受
- 日期：2026-10-21
- 关联：首页使用统计展示；ADR-0004 会话隐私与传输安全；产品规格第 3.1、9.2、10 节

## 背景

受控试行需要一个轻量的使用情况反馈：首页展示“今日使用”和“累计使用”，让试行组织者
和民警了解工具是否在被真实使用。此前产品没有账户体系，也不保存分析记录、事实、报告或
页面轨迹，因此不能通过用户身份、会话历史或内容日志统计使用次数。产品规格还明确禁止在
文书范例浏览中展示热门、使用次数或最近浏览，以免把内容浏览变成推荐或行为追踪。

## 决策

1. **只统计三个入口的“受理”，不统计页面浏览量。** 一次计数发生在：
   - 案情分析提交被受理（流式开流，或结构化分析会话创建成功）；
   - 交通事故责任认定新建问答会话成功；
   - 文书范例正文被成功打开。
   文书列表、检索、筛选、失败请求、限流请求和页面刷新不计数。

2. **只保存三个数字和一个日期。** 持久化文件仅包含累计次数、当日日期和当日次数；
   不保存请求编号、匿名令牌、IP、用户代理、案情、事实、报告、检索词、页面路径或
   任何可用于关联多次使用的标识。计数无法还原“谁在什么时候做了什么”。

3. **按配置时区跨日。** 默认使用 `Asia/Shanghai`，可通过 `PM_USAGE_TIME_ZONE`
   覆盖；跨日时今日次数归零，累计次数不清零。接口返回当前日期与时区，首页只展示数字。

4. **计数失败不影响业务。** 统计文件由 `PM_USAGE_STATS_FILE` 指定；写入失败或文件损坏时
   退回进程内存计数，不向分析请求抛出异常。未配置或显式设为 `off` 时仅保存在内存。
   测试环境默认不落盘，测试控制接口可重置计数。

5. **首页展示不是历史、排行或推荐。** 首页只显示今日与累计两个静态数字和一句口径说明；
   不提供点击、下钻、个人历史、热门排行、算法推荐或最近浏览。它不改变三个同级主入口的
   信息架构，也不构成新的功能入口。

6. **披露口径。** “使用与数据说明”页面在“允许记录的非内容元数据”中列明该计数只包含
   累计次数、当日日期与当日次数，不包含身份、令牌、IP、案情或页面轨迹。

## 后果

- 单实例部署下，计数反映该实例受理的入口使用次数；多实例部署需要共享存储或分别展示，
  当前受控试行按单实例设计。
- 同一用户重复提交、重试和失败后的再次提交会被分别计数；该数字表示“受理次数”，
  不表示“独立用户数”或“成功分析数”。
- 发布/重启后从文件恢复累计次数；文件丢失时从零开始，不影响业务功能。
- 产品规格第 9.2 节“不展示热门、使用次数”的约束仍适用于文书范例列表和检索；
  本 ADR 只允许首页展示聚合计数。
