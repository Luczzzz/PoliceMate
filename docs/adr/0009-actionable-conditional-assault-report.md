# ADR-0009：殴打伤害报告保留明确方向与可执行核验

- 状态：已接受；其“例外仅适用于殴打伤害类”的范围由 ADR-0010 在真实 Dify 分析路径上推广到全部受治理重点案情（fixture 仍保留原有保守降级，殴打伤害类保留本 ADR 例外）；第 5、6 条关于依据失效、冲突、生成失败继续整体降级的部分仍然有效。
- 关联：ADR-0008；产品规格 7.2、7.4；`CONTEXT.md` 的初步定性意见、程序建议和决定性事实缺口。

用户需要六模块报告直接给出涉嫌行为方向、受理调查建议、取证优先级、分角色问题、程序风险和实际引用的条文，而不是缺少伤情就用同一条警示替换初步定性、受立案和法律依据三个模块。现有机械降级误把“伤情未查明”扩散为“所有程序都无法建议”，并清空了仍然有效的依据。

殴打伤害类的正常、无冲突报告允许保留受当前有效受治理法源支持的条件性分析：总体仍标记事实不足，初步定性明确列出涉嫌殴打或故意伤害方向、未知条件与转换条件；受理调查和法律依据模块按各自可支持的内容呈现，不因为缺少伤情一并清空。未提及伤情不是无伤情，饮酒不是醉酒失控，发生在公共场所不等于寻衅滋事；不存在材料不能标为已掌握。法条处罚幅度可以作为原文参考，但不得据简短输入推荐本案处罚档次。

此例外仅应用于受治理殴打重点案情和指定的详细生成版本。其他案情、相邻方向冲突、争议事实、依据失效和关键生成失败继续沿用现有保守规则。报告仍与快照绑定，每条依据继续标注事实确认状态；未来接入真实 Dify 必须满足同样的输出和校验要求。当前实现是确定性规则报告，不宣称已接入真实模型或已获得机关审定。
