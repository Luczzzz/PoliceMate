# ADR-0004：会话隐私、传输安全与失败降级

- 状态：已接受
- 日期：2026-09-28
- 关联：`#32 落实会话隐私、安全和失败降级`，产品规格第 10、11、12、14、17、18 节，
  决策票据 #24、#25

## 背景

第 32 号切片要把产品收敛到受控试行所需的会话生命周期、隐私、传输安全和
失败降级边界，并证明案情与报告内容不会进入持久化存储、URL、日志或第三方
遥测。前序切片已经把会话与临时工作台放在当前标签页内存中，但缺少传输层
防护、超时/重试策略、结构化反馈、可机械核验的发布检查，以及覆盖
canary 泄漏、取消、超时与独立降级的自动化测试。

## 决策

1. **传输层防护放在 PoliceMate 后端，不改变产品状态机**。后端在 `onRequest`
   校验来源：无 `Origin`（非浏览器/同源可达）允许，命中 `PM_ALLOWED_ORIGINS`
   白名单允许，否则要求 `Origin` 的 host 与请求 `Host` 一致（同源部署）。
   请求体由 Fastify `bodyLimit` 限制（默认 128 KiB），超过时返回
   `request_too_large` 且不截断。

2. **短期匿名令牌只用于限制未授权流量，不构成身份认证**。后端签发随机
   令牌（`POST /api/v1/anonymous-tokens`，默认 30 分钟有效，只存进程内存），
   分析、文书检索与反馈接口必须携带 `x-pm-anonymous-token`。令牌过期或缺失
   返回 401 `token_invalid`；H5 在收到 401 时清除内存令牌、重新获取并重试
   一次。令牌不进入 URL、存储或任何用户可见内容，也不表达身份或权限。

3. **频率与并发限制按令牌计数**。受保护接口使用固定窗口限流（默认
   300 次/分钟），令牌签发按来源 IP 限流；同一令牌的分析在途请求受并发
   闸门限制（默认 4）。超限返回 429 `rate_limited` 与 `Retry-After`，H5 显示
   独立的“请求过于频繁”状态。

4. **外部边界超时与单次重试**。事实提取与追问单次最多 30 秒，完整报告
   最多 90 秒（`PM_ANALYSIS_TIMEOUT_MS` / `PM_REPORT_TIMEOUT_MS`）。空结果、
   结构错误、来源校验失败或超时最多自动重试一次（`PM_MAX_PROVIDER_ATTEMPTS`，
   默认 2 次尝试）；仍失败则失败关闭，返回 503 与随机请求编号，绝不展示
   半成品，后端不自行补写或改写结论。

5. **只记录非内容运行元数据**。遥测通过白名单事件类型记录：随机请求编号、
   时间与耗时、状态与错误分类、契约/工作流/内容批次版本、输入输出字符数、
   重试/取消/限流情况、已匹配法源记录 ID、匿名页面/功能状态。查询字符串与
   响应正文不进入遥测；内存写入端在持久化前再次按白名单裁剪字段。HTTP
   层在 `onResponse` 记录路由模式、状态与耗时。

6. **客户端在途请求可取消，迟到响应不得写回**。H5 用 `AbortController` 与
   递增代次（epoch）管理在途请求；清除、取消或确认新快照会中止在途请求并
   使迟到响应失效。报告响应必须匹配请求编号与事实快照哈希，否则丢弃。
   提交后在 1 秒内显示真实阶段与已等待时间，提供取消入口，不显示百分比。

7. **存在未清除案情时设置通用离开提醒**。`beforeunload` 只在当前标签页持有
   有效会话时注册，提示不含案情摘要；浏览器不显示提醒时产品不承诺恢复。

8. **结构化反馈只提交预定义类型与白名单元数据**。反馈接口只接受固定类型
   与 `pageId`/`featureState`/`contentReleaseId`/`workflowVersion` 白名单字段；
   未知键、自由文本或非法取值一律拒绝。页面不提供自由文本框。

9. **合法链接协议白名单**。只有 `http(s)` 官方来源链接可以渲染为可点击
   链接；服务端返回前与客户端渲染前各做一次协议校验，非法协议（如
   `javascript:`）渲染为不可点击文本。

10. **发布检查机械核验可核验门槛**。`npm run release:check` 校验使用与数据
    说明已填入实际服务主体、联系人、数据处理说明与技术日志边界（空值或
    占位值即失败）、合格文书范例不少于 6 个、生产环境禁用测试控制、Dify
    基地址使用 HTTPS、生产环境允许来源不含明文 HTTP。

## 后果

- 受控试行单实例部署下，匿名令牌与限流记录都在进程内存；多实例部署需要
  粘性会话或共享令牌/限流存储，生产化前需重新评估（仍然不得持久化案情）。
- 令牌 TTL 短于标签页空闲上限时，活跃标签页会在下一次受保护请求自动换发
  令牌；不会因此丢失当前会话状态。
- 真实 Dify 接入时只需实现适配器；超时、重试、校验、遥测与失败关闭逻辑
  不变。
- 发布检查当前会因缺少实际服务信息与至少 6 个合格文书范例而失败，这是
  预期行为；相应内容由后续内容切片补齐。
